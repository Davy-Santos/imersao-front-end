# imersão-front-end

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3 (com Flexbox e Grid)
- JavaScript (ES6+)
- Fonte: [Google Fonts](https://fonts.google.com/)
- Ícones: [Phosphor Icons](https://phosphoricons.com/)

## 🛠️ Funcionalidades

- 🎵 Interface principal inspirada no Spotify
- 📱 Design responsivo
- 🧭 Barra lateral com navegação
- 💿 Listagem de álbuns e playlists
- 🔍 Campo de busca visual

## 📚 Aprendizados

Durante o desenvolvimento deste projeto, foram aplicados diversos conceitos como:

- Organização e semântica em HTML
- Estilização moderna com CSS3 (Flexbox, Grid, variáveis)
- Responsividade
- Estruturação de componentes reutilizáveis
- Boas práticas com arquivos estáticos

## 🧑‍🏫 Créditos

Projeto desenvolvido como parte da [Imersão Front-End da Alura](https://www.alura.com.br/imersao).
